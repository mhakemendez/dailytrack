
# AI Development Team

A small AI-powered development team for building full-stack web applications.

## Team

- Project Manager: ChatGPT
- Full-Stack Developer: OpenCode
- QA Engineer: OpenCode

## Technology Stack

- Next.js
- NestJS
- TypeScript
- PostgreSQL
- Prisma
- npm Workspaces

## Getting Started

Install dependencies:

```bash
npm install
```

Start frontend:

```bash
npm run dev:web
```

Start backend:

```bash
npm run dev:api
```


# AI Development Team Instructions

## Technology Stack
- Frontend: Next.js App Router (without src directory)
- Backend: NestJS
- Language: TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Package manager: npm workspaces

## Team Structure
- Project Manager: ChatGPT
- Full-Stack Developer: OpenCode subagent
- QA Engineer: OpenCode subagent

## General Rules
- Follow approved requirements.
- Do not invent features or requirements.
- Keep implementations simple and maintainable.
- Reuse existing components and services.
- Avoid unnecessary dependencies.
- Do not modify unrelated files.
- Follow existing coding conventions.

## Development Workflow
1. Read relevant project documentation.
2. Review the assigned task.
3. Implement only approved requirements.
4. Run relevant tests and builds.
5. Report completion to the Project Manager.
6. Wait for QA verification when required.

## Communication
- Report blockers immediately.
- Explain important technical decisions briefly.
- Never claim something works without verification.
- Do not silently change approved requirements.

## Application Structure
- apps/web: Next.js frontend
- apps/api: NestJS backend
- docs: Project documentation
- .opencode/agents: AI agent definitions
